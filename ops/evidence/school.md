# 公立 K–12 搬家入学：证据记录

作者 `/root/health`；实际查阅 2026-10-13。支持 `content/book/people/school/school-enrollment.md`。本记录是作者研究，不是独立事实审。正文为 written / draft true；审阅字段空。

## 范围与方法

全国共同概念只用于当地居住家庭的公立基础教育、一般办理方法及联邦权利；四州规定明确归属，加州 / 旧金山、纽约州 / 纽约市、华盛顿州 / 西雅图、得州 / 奥斯汀区分州与学区。不得外推都会区、国际学生专程留学项目、私校或高等教育。所有采用的具体来源均实际打开正文；搜索仅发现入口。网页失败时使用普通 HTTPS、TLS 验证开启的 Python urllib + BeautifulSoup 读取正文。无私人账户、申请提交、电话联系或成功入学实测。

## 冲突、访问失败与没有核实的项目

- Seattle 登记页上一般 2026–27 流程与标注 2025–26 的 MV intake 文案混在一起；后者称新生须先判定、会 hold。独立读到同学区现行公开 Board Policy 3115 与联邦 §11432(g)(3)(E)，明确资格争议期间立即入学。正文不把网页 hold 概括成合法的普遍先决条件：普通材料清单旁明确例外，MV 部分以法条 / 正式政策为依据，并给联络员、书面决定及争议途径。未实际询问该网页执行情况，不能声称已消除当地后台流程差异。
- ED 2026-08-04 McKinney–Vento non-regulatory guidance PDF 通过 web、普通 HTTPS 与正常代理均 403；没有读到正文，不作为采用来源。2024 法典的所用条文由当前公开州 / 学区指引交叉支持；本文不声称已审查新指南全部变化。
- NYSED 联合指引及 enrollment brochure：web 502，普通 HTTPS / 正常代理 TLS 证书链失败；未关闭 TLS。改用共同发布方 NY OAG 的可读正式正文，不以搜索摘要代替。未采用纽约具体登记工作日期限和所有健康规则。
- CDE newcomer 页面循环重定向 / HTTP 303；未采用其正文。可访问 CDE 年龄 FAQ、SFUSD 及联邦 / 州级原文支持本稿所写核心流程。
- Austin enrollment-101 旧链接 web 失败、普通 HTTPS 404；仅采用当前 `/enroll` 页面。未采用搜索发现的 2017 TEA 信件、旧 Austin 文档或旧申请截止日期。
- 没有核验读者的真实地址、房源、学区边界、个人年龄 / 疫苗、个案监护权限、年级或学位空缺；正文把这些转为应向学区确认的具体问题。学校评分无数据断言，不给学校排名 / 置业结论。
- 没有操作当地申请系统、获取学生 ID、加入候补、访问个人健康或教育记录。只验证公开办事页面的路径和说明。英语支持、IEP / 504、寄养全部程序、校车 / 餐食资格保留后续地图；本页只做材料与负责人交接。
