# 四州迁入驾照证据

作者 documents；实际查阅 2026-10-13；稿件 `content/book/life/transport/new-resident-license.md`，18 岁以上普通非商业小客车驾照。完整稿 written / draft true，未自行核验通过、构建或提交。证据是作者研究，异人审阅另记。

## 阅读方式

以下采用 web open/click 实际取得正文，或正常 HTTPS urllib 读取后用 BeautifulSoup 提取正文。WA 的 web open 多次 403，但正常 HTTPS 直连可读取相同官方原文；没有绕过挑战或关闭 TLS。PDF 在工具中阅读，或内存下载并用 pypdf 提取，无新增大文件。搜索摘要只用于发现入口。
