## 留待独立主题研究

- SNAP 与 TANF：本页只分流。2025—2026 年移民类别、州资助替代项目、家庭成员、不申请成员资料、收入扣除、工作要求、加急与听证须按州及具体项目重新回源，不由 UI 结论外推。
- 医疗或照护导致无法工作：工伤、州带薪家庭医疗假、伤残保险、SSDI／SSI 与 UI 的交叉资格另研究；本页仅提醒如实申报并询问相应项目。
- UI 完整金额与持续周数：本页不做四州给付计算器，不承诺到账速度、最高金额或固定 26 周；等待周、重开原申请、第二个福利年度、扩展福利与超付追偿需专题。
- 特殊工作：联邦、军人、铁路、农业家政、学校假期、劳资争议、承包与平台、自雇、派遣及工会召回细节不套普通雇员模板。错误分类时保留申请和机构判定路径。
- 雇主身份关联：H／L／O／E／TN、F／J、授权自动延展及 pending 文书逐项核对；本页不承诺宽限期长度，不把 SSN 或当前 EAD 当作过去工资有效的唯一证据。
- 地方紧急支持：按实际地址、开放时间、资金与项目资格查询；本页不保证现有租金名额、库存或安置床位。不将全国目录当成个案受理结果。
- 离职协议与 WARN：补偿、保密、放弃权利、提前通知、退休账户等需要独立成篇；本页只要求保存与核对文件，不给统一签约建议。
