## 第一轮核心路径与收口条件

当前B01—B07的30篇是中间成果。第一轮先补明显缺章，再走通下表的常见问题；同一行动链可合并主题，不设篇数或统一长度。研究后可调整拆合，但核心条件、文件、主管入口、完成记录及受阻继续路径须有正文承接。

| 读者问题 | 已有承接 | 第一轮仍须补的核心 |
|---|---|---|
| 怎样理解美国社会和公共制度 | 地区比较、隔离／民权、Tribal Nations、政府分工、社交边界、美国与世界的联系 | 建国与移民社会的历史叙事、公共参与 |
| 初次抵达或跨州搬家 | 身份文件、号码、地址、租房、驾照、医保、税务 | 手机／宽带与日常账户、实际通勤／车辆手续、抵达事项整合 |
| 怎样租住或购置住房 | 四州租赁、押金、维修与通知 | 自住购房、贷款／验屋／产权／交割及持续住房成本 |
| 怎样经营家庭日常与社区生活 | 地区选择和服务沟通 | 购物／标签／账单／退货、水电等住户服务、图书馆／社区资源；真实本地服务案例 |
| 怎样选择就医并处理账单 | 保障费用、网络预约、EOB／账单申诉、换保 | 退休时Medicare的实际接续；心理健康及无障碍需要的服务链 |
| 家庭关系和孩子怎样安排 | 孕产、出生文件／加保／随访、入学 | 成人婚姻与证明、托育选择、在校语言／残障／安全支持 |
| 怎样继续学习或改变职业 | 入学及服务语言 | 高等／职业教育选择、资助资格与申请、海外资历及学徒等入口 |
| 成年亲人需要照护、退休或去世 | 成年亲人照护与四州服务申请、出院和家庭替班 | 退休收入及医疗接续、意愿／授权文件、死亡手续／殡葬／遗属与遗产分流 |
| 怎样开始工作及维护劳动权益 | 求职录用与入职、工资／加班与欠薪、失业UI／申诉 | 职场沟通、休假／工伤／歧视等受理与时限；不套同一employee定义 |
| 怎样安排钱并应对经济困难 | 银行付款、信用／冻结／纠错、失业支持分流 | 借贷／催收、储蓄与税惠账户、食品现金支持的四州实际申请条件和受阻路径 |
| 怎样完成税务及跨境记录 | 联邦税务身份、四州居民及跨州收入 | 年度申报／支付／延期／更正、海外收入与账户报告的适用分支 |
| 怎样开始并经营生意 | 身份与文件、银行、税务基础 | 实体／EIN／许可／账户／记录／税务／雇佣及停业链，四州和实际地方主管 |
| 收到合同、法律文件或意外通知怎么办 | 个人消费与服务合同、法律帮助、工资／住房／医疗的具体通知 | 真实送达／期限与文件识读、事故及索赔；各程序分开 |
| 遇到灾害、出行或户外风险怎么办 | 紧急求助与定位 | 四州灾害计划／撤离／恢复、户外许可／路线／通信、国际出入境和返美文件；家庭枪支安全与法域边界须明确承接 |

第一轮不复制50州的全部手续，也不把每项低频专家程序设为完成门槛。辅助生殖／收养的完整案件、复杂信托与企业重组、各类专业执照、全部产品计算器、所有属地福利等延伸细目保留在地图，并在相关主题说明确切未覆盖范围。地图中的“必须考虑”须有实际正文或合理的范围说明，不能默默消失。

最后按抵达、搬家、求职、失业、入学、就医／账单、创业、照护和丧亲实际走查；四州、不同身份／家庭、城乡、语言及无障碍条件同步审查。核心行动断点、地区错配和重大资格遗漏未修正前，目标保持active。只在范围与实际产物相符、独立审阅、构建及渲染全通过后交付第一轮结果和延伸队列。
