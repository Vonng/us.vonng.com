在美国办事，先确定 **什么事项、发生在哪里、谁发出文件** 。联邦、州和地方机关各有权限；同一个地址也可能同时属于某个县、城市、学区和供水区。找到主管后，再查该项服务的资格、材料和申诉办法，比笼统寻找“政府部门”更有效。

## 联邦制怎样落到日常生活

美国宪法将一定权力授予联邦，第十修正案把未授予联邦、也未禁止各州行使的权力保留给州或人民。这是联邦制 federalism 的基础。它使全国性制度与各州自己的法律、机构长期并存；具体事项还可能同时受几种规则约束。[国家档案馆：第十修正案原文](https://www.archives.gov/founding-docs/bill-of-rights-transcript)

联邦内部又分三个部门：国会 Congress 负责立法；总统领导行政部门 executive branch，各主管机构执行职权范围内的事务；联邦法院 judicial branch 在案件中解释和适用法律，审查合宪性。平常申请证件或查询待遇，通常先接触行政机构；要挑战一项决定，则需要找到通知列出的复议、听证或法院程序。[USAGov：联邦政府三部门](https://www.usa.gov/branches-of-government)

寻找入口时可以这样缩小范围：

| 手上的问题 | 先找什么 |
|---|---|
| 文件抬头写着联邦机构名称，例如 IRS、SSA、USCIS | 从 [联邦机构目录](https://www.usa.gov/agency-index) 找到该机构，再进入通知对应的具体事项 |
| 州发出的许可、税务或待遇通知 | 查 [州政府目录](https://www.usa.gov/state-governments)，核对州名、部门全称和案件号码 |
| 住宅、道路、地方服务或当地条例问题 | 从 [地方政府目录](https://www.usa.gov/local-governments) 找到实际县、市或镇，再查该项服务覆盖的地址 |
| 学校分配、供水、公交等问题 | 查实际学区、服务区或运营机构，确认地址是否在服务范围内 |
| 已收到法院文件 | 按文件所列法院、案号和程序查询；把答复或出庭日期单独记下 |

表里的目录用于确认机构身份。实际递交前还要进入该事项的办理页，核对收件机关与地址；同一机构也会有不同表格、办事处和收件渠道。

## 县、市、学区和服务区不一定一层套一层

County 通常译作县，但地方制度并不全国一致。人口普查局的政府分类包括县、市镇、township、独立学区及特别服务区；它把阿拉斯加的 borough、路易斯安那的 parish 归入相应的县级政府类别。独立学区可以有自己的行政和财政权力；特别服务区可能只负责供水、消防或公共交通等有限事务。也有学校系统由其他地方政府直接管理。[Census：政府组织术语](https://www.census.gov/programs-surveys/gus/about/glossary.html)

因此，搬家前可以分别问三个问题：这个地址由哪个地方政府管辖；孩子应向哪个学区申请；供水、垃圾、消防等服务由谁提供。答案未必都是同一个城市名称。城市边界以外的住宅，也可能使用那个城市的邮寄地址。

**邮寄地址中的 city 和 ZIP Code 不能单独证明行政归属** 。人口普查局明确说明，邮政使用的城市名可以与住宅实际所在的 municipality 或 district 不同。确认本地条例和学校时，用完整街道地址查主管机构的地图、地址查询工具或向其工作人员确认。[Census：邮政城市名与行政地理](https://www.census.gov/programs-surveys/geography/guidance/geo-areas/usps_census_city.html)

“湾区”“纽约都会区”这样的区域名适合描述生活与通勤范围。查询具体租赁规定、停车规则或入学条件时，仍要落到房屋或事件所在的法域。

## 特区、属地和 Tribal Nations 怎样查

哥伦比亚特区 District of Columbia 有自己的市长、议会和法院体系。它的自治框架来自 Home Rule Act，国会仍保留为特区立法和推翻地方法律的权力。在华盛顿特区居住，应查 DC 的主管机构，不能套用邻近马里兰州、弗吉尼亚州或华盛顿州的手续。[DC：政府组织](https://oca.dc.gov/page/dc-government-organization)

属地也应按具体地方查询。USAGov 的 [州与属地政府目录](https://www.usa.gov/state-governments) 分列 Puerto Rico、Guam、American Samoa、Northern Mariana Islands、U.S. Virgin Islands 等入口。涉及联邦税、移民、福利或公民身份的问题，还要看相应联邦规则怎样定义该属地；仅凭“美国境内”不足以确定适用条款。

Tribal Nations 是具有自身治理权的政治共同体。获得联邦承认的 Tribal Nations 与美国联邦政府存在政府间关系，不能把它们画成县市之下的一级。其权限受到条约、联邦法律和法院判决等影响，具体管辖还会涉及土地、当事人身份及争议类型。[BIA：法律地位、部落主权与自治权限](https://www.bia.gov/frequently-asked-questions)

以 Cherokee Nation 为例，其自身宪法构成行政、立法和司法三部门的框架。查询这一地区的事务，需要阅读 Nation 自己公布的法律与服务说明；另一个 Tribal Nation 未必采用相同政府结构或服务条件。[Cherokee Nation：宪法与政府框架](https://www.cherokee.gov/our-government/cherokee-nation-constitution/)

如果事情涉及部落土地、部落法院或成员资格，先记录具体 Nation 名称、地点和收到的文件，再联系文件所列机构。不能因为邮寄地址位于某州，就只按州的一般流程处理。

## 看到“新规定”时，要读哪一种文件

政府网站上既有现行法律，也有提案、说明和新闻。阅读时先找文件类型，再看日期和适用对象。

| 文件上的词 | 能告诉你什么 | 接下来查哪里 |
|---|---|---|
| Bill、Act、Statute | Bill 是议案；通过立法程序后才可能成为法律 | [Congress.gov 的法律检索入口](https://www.usa.gov/research-laws)可查进度；U.S. Code 按主题汇编多数现行联邦成文法 |
| Proposed rule、Final rule、CFR | 机构提出或正式发布的法规；提案的公众意见截止日与正式规则生效日用途不同 | 看文件的 Dates、Effective Date、适用日期，以及主管机构当前执行说明 |
| Executive Order | 总统向行政机构和官员发布的行政命令 | 核对正式文本、命令编号、适用机关、执行步骤和后续变更 |
| Guidance、FAQ、Policy manual | 机构对现有法律或法规的解释与办理指引 | 追到所引法条，确认页面版本、适用人员和当前表格 |
| Court order、Opinion、Injunction | 法院在具体案件中作出的命令或意见 | 看法院、案号、日期、命令正文，以及后续上诉或暂停执行的情况 |

联邦机构的法规须有授权依据；解释性指引用于说明现有规则，不能凭指引另设新的法定义务。正式规则的生效日、适用日、遵守期限也可能不同。[Office of the Federal Register：法规制定指南，第 2、7、11 页](https://uploads.federalregister.gov/uploads/2013/09/The-Rulemaking-Process.pdf) 行政命令的正式出版与查询方式见 [GovInfo：Executive Orders](https://www.govinfo.gov/features/executive-orders)。

新闻写“法院叫停”时，先查原始命令及主管机关最新说明，确认暂停的是哪一条、适用于哪些人、从什么时候开始。地方条例则应回到相应市县公布的 code 或 ordinance，不能只找联邦法。

## 联系错部门，或被来回转介

准备一份短记录：事项、完整地址、文件名称、案件或申请号码、收到日期、已经做过的步骤、希望解决的问题。与工作人员沟通时，可以具体问：这项服务是否由你们负责；如果地址不在范围内，应该联系哪个机关；是否有书面办理说明和收件证明。

以下为教学虚构表达：

> “Which agency handles this for this address?” 这个地址的这件事由哪个机关负责？
>
> “Could you point me to the written rule and the appeal instructions?” 能否告诉我书面规则和申诉说明在哪里？

保留转介部门名称、网页、通话日期和回执。已经收到拒绝、罚款或出庭通知时，优先读通知中的答复路径和期限；询问一般客服之后，也要继续处理文件要求的正式步骤。
