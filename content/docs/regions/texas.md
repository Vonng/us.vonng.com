迁入、工作或给孩子办入学时，先在下列正文中选择本州分支。使用城市或学区案例前，确认自己的完整地址确实属于相应机构的范围。

- [租房申请、维修与交房](/book/life/housing/rental-process/)：查本州申请费用、书面通知与押金结算，遇到法院文件时进入对应应诉与帮助渠道。
- [失业或搬家后接上医疗保险](/book/people/health/coverage-changes/)：按家庭成员查本州市场与公共保障入口，确认旧保结束、新保生效及持续就医。
- [跨州搬家与远程工作的州税](/book/work/tax/state-residency/)：保留住所、工作地点和扣缴记录，分别核对居民期间与收入来源。
- [新居民驾驶证](/book/life/transport/new-resident-license/)：按原驾照签发地、有效期和年龄核对材料与考试；州内地址更新也在同一页。
- [工资单与加班费](/book/work/employment/pay-stub-overtime/)：根据实际工作地点、工作周和职责查费率与处理入口。不同工资请求的受理范围须分别核对。
- [失业或工时减少](/book/work/employment/job-loss-support/)：查 TWC 工资条件、指定申报日的支付请求和首次申诉；不要套用其他州的替代基期与期限。
- [孕产保障与出生手续](/book/people/family/birth-and-first-weeks/)：先认清批准的是完整 Medicaid／CHIP 还是 CHIP Perinatal，再安排产后服务与孩子加保。
- [寻找法律帮助](/book/rights/legal/finding-help/)：核对州律师转介的初谈条件，免费或低费帮助另走对应入口。
- [求职与入职](/book/work/career/job-search-onboarding/)：找 Workforce Solutions 的实际服务区，休斯敦案例连接求职、面试与全州职位系统。
- [成年亲人的照护](/book/people/aging/caregiving-plan/)：核对 STAR+PLUS、服务协调与 HCBS 的不同进入路径，再查完整 Medicaid 资格。
- [消费与服务合同](/book/rights/contracts/reading-contracts/)：整理 OAG 投诉材料，个人请求继续核治安法院、司法辖区、传票与送达。
- [孩子入读公立学校](/book/people/school/school-enrollment/)：从州级边界进入奥斯汀案例，确认当地登记、学校分配与材料不足的处理；同一都会区的其他学区另查。
- [手机与家庭网络](/book/life/digital/phone-internet/)：先核住址、设备与完整报价；补助从联邦 Lifeline 的得州适用入口继续，服务投诉按具体业务找主管。
- [日常购物与退货](/book/life/household/shopping-returns/)：核商家政策、收据和多收费；TDA 称重计价投诉、OAG 消费投诉与金融争议分开。
- [图书馆与社区服务](/book/life/community/local-support/)：休斯敦市 HPL 与 Harris 县 HCPL 是不同系统；临时卡、设备会员和儿童项目另核材料及报名。
- [自己接单或开小店](/book/work/business/start-business/)：Austin／Travis 县实例分别查名称登记、场地和州税务，再接实际经营、报告与停业。
- [成人继续学习](/book/people/education/continuing-education/)：Houston City College 连接州居民与服务区、TASFA／TEOG、注册和退出；其他地点从 THECB 项目目录继续。
- [公园、步道和营地](/book/rights/outdoors/outdoor-planning/)：Brazos Bend 的日票、营位和无障碍预约各核确认，再查当天禁火、路段与鳄鱼安全说明。
- [年度报税办理](/book/work/tax/filing/)：本州个人所得税条件与联邦、其他州及经营义务分别核，保存各项受理和付款记录。
- [语言与残障便利](/book/people/accessibility/accommodations/)：工作、住房和学校请求沿各自负责人及主管继续，州法与联邦范围分开核。
- [心理健康支持](/book/people/accessibility/mental-health/)：按县或 ZIP code 找 LMHA／LBHA，核评估、材料与费用；Harris County 例子另按服务区继续。
- [自住购房](/book/life/housing/buying-home/)：签报价和付订金前核购买资格及持有方式；经纪协议、当前表件及实际地块的 CAD／Clerk 分工分别确认。
- [水电燃气与垃圾](/book/life/household/utilities/)：休斯敦先分售电商和送电公司，市营与合作社地址另走适用分支；水与垃圾责任按实际服务区核。
- [结婚与分居离婚](/book/people/family/marriage-separation/)：Harris County办证之外先核现有关系，法院文件、送达、答复及判令按具体程序继续。
- [退休收入与Medicare](/book/people/aging/retirement-medicare/)：找HICAP咨询，向HHSC核费用援助，线上表件不能打开时继续索取纸件或协助。
- [买车、登记、保险与卖车](/book/life/transport/owning-car/)：按TxDMV及实际县核购车、title、登记、保险和当前检查要求，卖车后保存转让及通知结果。
- [托育与费用支持](/book/people/family/childcare/)：分HHSC许可监管与DFPS儿童保护，向实际Workforce Board查费用支持、候补、邀请及转提供者。
- [医疗意愿和代理授权](/book/people/aging/advance-planning/)：取完整医疗POA／directive与财务法定表，分别核签署、生效和权限；院外OOH-DNR按自己的表与医生确认。

还没有分清州、城市和学区的职责时，可先读[这件事该找哪一级政府](/book/foundations/government/which-government/)。联邦[税务居民判定](/book/work/tax/tax-residency/)和[医疗费用结构](/book/people/health/insurance-costs/)解释共同概念；州税与保障衔接使用上方具体分支。

[公共交通往返](/book/life/transport/public-transit/) 的休斯敦METRO与METROLift按实际服务范围和预约条件核，乡村或其他城市从真实主管继续。[公共参与与投票](/book/foundations/government/public-participation/) 分开Houston会议与得州选民手续；新登记、迁县有限票、现场证件和邮寄资格分别走适用程序。

在校英语、评估及支持计划，沿[学校支持](/book/people/school/school-support/)核得州程序和Austin ISD实例，区分请求、家长同意、ARD及实际实施。

工作受伤或歧视时，沿[职场权利](/book/work/employment/workplace-rights/)先核雇主是否参加工伤保险，再分别走DWC争议或正式歧视投诉，收入支持资格另查。

亲人去世后，沿[死亡手续](/book/people/aging/death-arrangements/)分Houston城市服务范围与其他登记机关；由Harris IFS经办的案件，其医学部分由IFS填写，家属证明另向发证机关申请。
